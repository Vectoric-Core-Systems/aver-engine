Aver Node Gameplay with no C# at all A graph file IS the class asset, compiled straight to IL. New in 0.3.
Materials A surface wired instead of written DOMAIN material compiles a .ocgraph straight to HLSL -- one generated shader, switched per draw. New in 0.4.
Fluids Density is real, viscosity is a fit Real densityKgM3 and a calibrated viscosityPaS drive a Jolt soft-body pool through one resolver, with buoyancy deliberately left out. New in 0.4.
Synapse A sight cone, a baked grid, a tree that decides Perception, 2.5D baked navigation and an eight-node behaviour tree, pure and scene-free until a composition root links them. New in 0.4.
